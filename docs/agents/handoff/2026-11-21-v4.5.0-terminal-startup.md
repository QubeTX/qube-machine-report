# TR-300 4.5.0 terminal startup

The report measures the current terminal on startup and reserves four rows for the prompt and shell messages. The local view prioritizes hardware and utilization. An interactive SSH login prioritizes the host, the server address reached by the connection, and battery status when available. The full report remains available with `tr300` or `report`.

## Shell behavior

The managed installers configure startup for the installing account. Windows Global and the macOS PKG also register machine-level hooks. Windows Corporate users can opt in with `tr300 install`. Windows PowerShell enrollment respects explicit policy and uses the account’s registered Documents destination. An SSH-only Windows account with a custom PowerShell login and a restrictive client default may need to run `tr300 install` once. Removing auto-run keeps both report commands and the preference across upgrades.
